# Конкурс детского рисунка — плагин WordPress

Версия 1.0.0 · WordPress 6.3+ · PHP 8.0+

Приём работ с модерацией, зрительское голосование без регистрации с защитой от накрутки, итоги, письма, роль «Модератор конкурса».

## Установка
Загрузите `dist/kids-art-contest.zip` через «Плагины → Добавить новый → Загрузить плагин» и активируйте.
После активации появится меню «Конкурс рисунков». Если страницы конкурса отдают 404 — откройте «Настройки → Постоянные ссылки» и нажмите «Сохранить».

## Быстрый старт
1. «Конкурс рисунков → Добавить конкурс»: название, описание, обложка, даты, возрастные группы.
2. Опубликуйте — страница конкурса `/konkurs/<slug>/` (архив `/konkursy/`) готова. Шорткоды: `[kac_contest id]`, `[kac_submit_form id]`, `[kac_results id]`, `[kac_contests status per_page]`; есть и блоки редактора.
3. «Модерация» — одобряйте работы (A / R, ← →).
4. «Голоса» — антифрод; «Итоги» — снимок, ручная правка, публикация, CSV/XLSX.
5. «Настройки» — защита, файлы, письма, согласия и сроки хранения ПД, внешний вид, права модератора.

## Файлы
- `docs/SPEC.md` — техническое задание, `mockups/index.html` — макеты экранов.
- `includes/` — ядро (CPT, фазы, голосование, итоги, REST, письма), `admin/` — админка, `public/` — шаблоны и JS/CSS, `blocks/` — блоки.
- Шаблоны можно переопределить в теме: `{theme}/kids-art-contest/*.php` (card, contest, gallery, form, results, work, leaders, contest-list, archive-kac_contest).

## Cron
Плагин использует WP-Cron (смена фаз, итоги, детекторы накрутки раз в 10 минут, очистка ПД). При `DISABLE_WP_CRON` настройте системный cron на `wp-cron.php`.
